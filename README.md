# JavaDona - PECL Paradigmas de Programación

Simulación concurrente y distribuida (Java RMI) de un supermercado.

## Ejecución RMI en local
1. Compilar el proyecto desde NetBeans.
2. Abrir consola en `JavaDona/build/classes`.
3. Ejecutar `set CLASSPATH=.` y `start rmiregistry`.
4. Arrancar el servidor y posteriormente el cliente remoto.
